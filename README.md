# AI-EL2-09 — Artificial Intelligence Projects

## 1. Introduction

This project implements three Artificial Intelligence (AI) concepts using Python:

1. **Expert System** — Analyzes electrical symptoms and provides possible diagnoses based on predefined rules.
2. **Search Algorithm Visualizer** — Implements Breadth-First Search (BFS) and Depth-First Search (DFS) to find paths between nodes and visualize the search results.
3. **Multi-Agent System** — Simulates multiple agents collaborating to complete tasks under the coordination of a manager.

The project uses graphical user interfaces (GUIs) and visualizations, where applicable, to demonstrate how these AI concepts work.

## 2. Requirements

The following software and tools are required to run this project:

- Python 3.10 or newer
- Visual Studio Code (recommended)
- Python extension for Visual Studio Code (recommended)
- Tkinter for graphical user interfaces
- Python standard libraries used by the individual programs

**Note:** Tkinter and `collections.deque` are part of the Python standard library in typical Python installations. No additional third-party libraries are required for the Search Algorithm Visualizer shown in this project.

## 3. How to Run

1. Install Python and, optionally, Visual Studio Code.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Open the integrated terminal in the project directory.
5. Navigate to the folder containing the Python program you want to run.
6. Run the corresponding Python file using the following command:

   ```bash
   python filename.py
   ```

   Replace `filename.py` with the actual name of the Python file you want to execute.

7. Follow the instructions displayed by the program and interact with the graphical interface, if available.

**Note:** Run each program using its corresponding Python file. The file names and directory structure may differ between implementations.

## 4. Results

The expected outputs of this project include:

- **Expert System:** Displays possible electrical diagnoses based on the symptoms selected by the user.
- **Search Algorithm Visualizer:** Allows users to select a starting node, destination node, and search algorithm (BFS or DFS). The application displays the resulting path, highlights the nodes along the path, and provides a search history through the **LIHAT RIWAYAT** button.
- **Multi-Agent System:** Demonstrates task assignments and collaboration among multiple agents under a manager's coordination.

Screenshots of program executions can be added to document the testing process and demonstrate the results.
